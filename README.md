# Independent Biosecure-LLM Safety Interface

This repository implements an interactive demonstration of the Biosecure-LLM framework (Palmer et al.). The architecture decouples the policy-enforcement plane from the underlying core Large Language Model (LLM) provider. Managing risk externally ensures that safety boundaries remain auditable, unalterable, and independent of commercial conflicts of interest.

## Core Features

* **Layer 1 Input Interception**: Vets user inputs before they reach the core LLM weights. Malicious intent or combination sequences trigger an immediate refusal state.
* **Layer 2 Output Sanitization**: Inspects text generated by the core model. If a response reveals actionable information or sensitive biological agents, the system applies contextual redactions rather than an opaque total refusal.
* **Independent Audit Ledger**: Generates a continuous compliance trace in JSON Lines format, completely isolated from the model execution parameters.
* **Wizard-Style Guided Interface**: Built for non-technical stakeholders to evaluate AI policy interventions through step-by-step telemetry where subsequent steps reveal themselves dynamically upon completion.

## System Architecture

The workflow follows a strict linear pathway:

1. **User Input Submission** (Step 1) -> 
2. **Layer 1 Input Scan** (Step 2 - Passes or Blocks) -> 
3. **Core AI Inference Engine** (Step 3 - Executed only if Layer 1 clears) -> 
4. **Layer 2 Output Scan** (Step 3 - Passes or Redacts content metrics) -> 
5. **Final Output Render & JSON Audit Update** (Step 4)

## Implementation Details

The web dashboard is built using Gradio 6+ and interfaces with an open-source model endpoint (`HuggingFaceH4/zephyr-7b-beta`) hosted via the Hugging Face Serverless Inference API. 

Policies are defined explicitly using a Policy-as-Code pattern within the application logic, allowing external oversight groups to modify rule thresholds without altering or retraining the foundational model weights.
